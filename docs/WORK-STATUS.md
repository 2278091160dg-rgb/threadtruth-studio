## 已确定的展示标准

同一白马甲、成年女模特，24个风格各一张六姿势预览。schema4保留原生整板与实际提示词／回执，另生成明确标注的排版衍生图。整板1200×1200、三列两行、每格360×480。3:4是**卡片外框**，完整姿势画面等比放入，可留白，不拉伸、不放大、不裁主体。

中文／英文风格名、模式副标题和“AI生成 · 排版衍生预览 · 非成片 / PREVIEW ONLY — NOT FINAL”由本地排版生成，不宣传为原生模型的精准版式。姿势1/2/4/6保留全身，3/5允许半身。排版不能修复服饰变形、人物不一致或原图缺失的身体部分。

旧3次尝试、旧提示词与失败结论不变。已使用登记的schema3韩系C原图验证新展示，复用不新增调用；第三次独立试验仍是历史证据。新展示、原生严格几何、人工验收、公开、完整主案例分别计数，任何软件检查不代填人工审核。
