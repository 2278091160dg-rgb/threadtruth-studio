## 纠正后的预览定义

同一白马甲 × 24 风格 × 每风格 1 张六姿势预览 = **24 张原生预览图、144 个姿势小格**。不是四张混合风格图，也不是 144 张独立高清成片。

沿用授权源图 6/7/8/14 和成年女模特。每张只加载一个注册风格包、使用原有动作 0 与六姿势母版，风格张力只借氛围，不改变服饰或性别。网页缩略图显示完整六宫格，点击打开同一张完整预览；不裁出某格、不放大冒充成片、不去标记。

生成前必须先关闭 T11。首先只做韩系冷感先导预览并交维护者检查；通过后逐风格推进。无可复用合格预览时，需要 **24 次初始原生调用**；先前错误的一次另记为偏差成本，不计交付。不得沿用旧的 4 次预算，不把任务排期当作无人值守批量生图授权；每个风格按原有动作 0 授权，重试单独明确。
