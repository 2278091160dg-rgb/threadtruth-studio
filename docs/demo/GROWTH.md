# Evidence-led GitHub growth

ThreadTruth Studio optimizes in this order: Codex for Open Source readiness, genuine adoption, then GitHub Stars. Images can improve conversion after a visitor arrives; they do not substitute for distribution, installation success, user evidence, or maintenance.

## Public evidence tiers

- **Primary Cases:** three authorized source-to-six-image workflows. Korean Cold Editorial is ready; E-commerce Studio and American Street remain planned.
- **Featured Styles:** eight high-signal styles for the README and sharing surfaces.
- **Full Style Index:** exactly 24 routed styles, each with at most one representative image until separately authorized and reviewed.

Planned cards must not display generated placeholders or imply completed evidence.

## 30-day cadence

- Week 1: publish the first complete case and Beta install path.
- Weeks 1–4: add no more than four separately authorized style representatives per week.
- Weekly: record GitHub's 14-day visitors, clones, referrers, popular content, Star change, and verified installations.
- When views rise without better installation or Star conversion, pause image production and fix positioning, installation, or documentation first.

No runtime telemetry is permitted. Public GitHub Traffic, Releases, opt-in Issues/Discussions, and consented case records are the evidence sources. Community announcements require separate maintainer authorization and must not buy, trade, or coerce Stars.
