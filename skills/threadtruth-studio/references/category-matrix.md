# category-matrix.md — 品类轴矩阵(与风格正交;core 横切,风格包不覆盖)

> **品类 ≠ 风格。** 本矩阵按服饰**品类**定保真重点 / 风险默认 / 推荐模式 / 性别年龄默认 / 适用红线;**与所选风格包正交**。优先级链(safety-core §3):平台政策 > 风险 > 品类/性别年龄 > 用途 > 风格。
> 来源:对齐 `recognition.md` §3 输入路由 / §4 风险等级 + `safety-core.md` R1/R4。pack **不得**改写本矩阵(品类由 core 横切)。

| 品类 | 保真重点 | 风险默认 | 推荐模式 | 性别年龄默认 | 适用红线 |
|---|---|---|---|---|---|
| 单件上衣 | 领型/肩线/袖型/衣长/下摆/门襟 | 低~中 | B 或 C | 按识别(女/男) | — |
| 连衣裙 / 长裙 | 裙长/裙摆层次/廓形;不加搭配 | 低~中 | C | 女装(按识别) | — |
| 衬衫 / 西装 / 大衣 | 版型/肩线/翻领/纽扣/结构 | 低 | C | 按识别 | — |
| 裤装 / 牛仔 | 裤型/裤脚/腰线/水洗 | 低 | B 或 C | 按识别 | — |
| 完整 outfit | 上下装+鞋包+色彩关系+层次,不重 styling | 低 | C | 按识别 | — |
| 针织 / 卫衣 | 织纹/廓形/版型 | 低 | C | 按识别 | — |
| 中式 / 东方结构 | 立领/盘扣/斜襟/面料肌理 | 中 | B 优先 | 按识别 | 禁古装/cosplay(recognition §3.7) |
| 文字 / 大 logo 款 | logo 位置/色块/视觉节奏,不发明 | 中 | B | 按识别 | safety-core R5(本地 IP/保真) |
| 露肤 / 吊带 / 短裙 | 去性感化 + 防走光 | 中~高 | B 优先 | 成人锁定 | safety-core R4(去性感化) |
| **泳装 / 内衣 / 比基尼** | 成人锁定 + 强去性感化 | **高** | B + 先 1 张测试 | **成人锁定** | **safety-core R4(交 moderation 裁决,被拦不绕过;不写死允许/禁止)** |
| **童装 / 母婴** | 年龄得体 + 安全日常场景 | **高(敏感主体)** | B 或 C | **儿童模特(core 注入)** | **safety-core R1(允许儿童模特;禁性化/暴露/危险;敏感品类如儿童泳装默认 flat-lay/挂拍/人台)** |
| 复杂礼服 / 透明 / 极端前卫 | 结构/材质/遮挡 | 高 | B + 先 1 张测试 | 按识别 | recognition §4 高风险 + prompt-build §6 fallback |
| 男装(各品类) | 同上对应品类 | 按品类 | 按品类 | **男模特(core 注入)** | 性别年龄轴横切,非风格 |

**使用规则:**
1. **性别年龄默认由 core 按本表 + recognition 识别注入**,pack persona 禁声明(safety-core §4 二次校验)。
2. 高风险品类强制走 `prompt-build.md §6` fallback(先棚拍测试);泳装/内衣叠 R4,童装叠 R1。
3. 品类与风格冲突(如"泳装 + 老钱克制风")→ 风险/品类优先于风格视觉,去性感化与 moderation 裁决不因风格诉求放宽。
4. 品类不确定 → 识别卡标"需确认",先问不猜。
