Boundaries / 边界

For apparel portraits, ecommerce and fashion editorial—not non-apparel products, text-only concepts, general virtual try-on, CAD fit, API integration, or unattended delivery. The garment source controls product facts. Gendered or culturally named styles translate atmosphere, styling, light and setting only; they do not infer a person's identity, ethnicity, nationality, body, or gender. / 用于服饰人像、电商和时尚编辑；不用于非服饰商品、纯文字概念、通用虚拟试衣、CAD 合体、API 集成或无人值守交付。源图决定商品事实；性别/文化风格名只翻译氛围、造型、光线与场景，不推断人物身份、族裔、国籍、身体或性别。

Install / 安装

Download the Plugin ZIP and matching .sha256 from the Releases page. Optional original-media ZIP is separate. This guide describes the published beta.3 prerelease. / 从 Releases 页面分别下载 Plugin ZIP 与匹配校验文件；可选原始媒体 ZIP 是另一份制品。本指南对应已发布的beta.3预发布版。

shasum -a 256 -c threadtruth-studio-1.0.0-beta.3.zip.sha256
unzip threadtruth-studio-1.0.0-beta.3.zip
cd threadtruth-studio-1.0.0-beta.3
python3 install-local.py
python3 install-local.py --apply
codex plugin add threadtruth-studio@personal --json

--apply registers the source at home directory → plugins → threadtruth-studio but does not enable it. Run the helper's exact printed Next: command because its returned selector is already the full plugin@marketplace value; the concrete command above is the default-personal example. Do not hand-edit config. Full bilingual instructions: docs/INSTALL.md. / --apply 注册到用户主目录 → plugins → threadtruth-studio，但不启用。运行安装器打印的完整 Next: 命令；返回 selector 已是完整 plugin@marketplace，上方是默认 personal 示例。不要手改配置。

First use / 首次使用

Start a new Codex task, upload a garment first, then enter exactly / 新建 Codex 任务，先上传服饰图，再原样输入：

请用 $threadtruth-studio 识别并推荐风格，不要生图

Expected: recognition card, recommended styles, complete catalogue, and no generation. Generation requires a later explicit choice and cost approval. / 预期为识别卡、推荐风格、完整目录，且不生图；后续生图需要另行明确选择和费用授权。

Privacy and cost / 隐私与费用

  • No runtime telemetry, extra API keys, connectors, MCP server, or fallback service. / 无运行时遥测、额外 API key、连接器、MCP 服务或降级服务。
  • After explicit generation approval, the host's native image provider processes the approved reference images and prompts and consumes host quota. / 明确授权生图后，批准的参考图与提示词会由宿主原生图片服务处理，并消耗宿主额度。
  • Outputs are kept locally or copied to the workspace the user chooses; the user controls deletion. Host-side retention follows the user's host account and provider policy and is not claimed to be local-only. / 输出保存在本地或复制到用户选择的工作区，由用户控制删除；宿主侧留存遵循用户的宿主账号和服务商政策，本项目不宣称仅本地处理。
  • Never publish customer media, credentials, private prompts, or full logs. / 不公开客户素材、凭据、私有提示词或完整日志。
  • Native generation stops if unavailable; there is no extra API or connector fallback. / 原生生图不可用时停止，不使用额外 API 或连接器降级。

For vulnerabilities use the private GitHub report.

Upgrade and rollback / 升级与回滚

Use a separately extracted, checksum-verified release. Because the active source exists, dry-run with python3 install-local.py --replace, then apply with --apply --replace and run the printed Next: command. Backups receive UTC names and the installed manifest gets a UTC cachebuster. On failure, restore with --source <reported-source_backup-path> --replace, dry-run first and then add --apply; never blindly overwrite marketplace config from its backup because later valid changes may exist. Re-enable using the newly printed command and start a new task. / 使用独立解压且校验过的版本；活动源已存在，因此 dry-run 必须带 --replace，再用 --apply --replace 应用并执行打印的 Next:。失败时以输出的 source_backup 路径作为 --source，先 dry-run 再加 --apply 恢复；不要用 marketplace 备份盲目覆盖后续合法变更。重新执行打印的启用命令并新建任务。

Troubleshooting / 故障排查

Plugin is not discovered / 未发现 Plugin

Confirm checksum, release root, helper output, exact selector, successful plugin add, then open a new task. / 核对校验、发行根目录、安装器输出、准确 selector 与 add 结果，再新建任务。

No image appeared / 没有出图

The first-use prompt deliberately forbids generation. Choose a style and explicitly approve a later action. / 首次提示明确禁止生图；选择风格后另行明确授权。
